# LateCompany

### Join Lethal Company lobbies after the game starts

LateCompany removes Lethal Company's restriction that prevents players from joining mid-game. Friends can now hop into your lobby at any point during a round, eliminating the frustrating wait between sessions.

<br>

---

## Features

| | |
|:---|:---|
| **Mid-Game Joining** | Players can join after the ship has already departed to a moon |
| **No Restart Needed** | Friends join the current round rather than waiting for the next |
| **Lobby Persistence** | Keeps your lobby open even after reaching the quota |
| **Server & Client** | Both host and joining players need the mod for full functionality |
